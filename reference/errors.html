Error codes ​

Run cluub errors CODE in a terminal for the same information.

CodeProblemHow to fix
E001Tabs used for indentationIndent with 2 spaces.
E002Indentation step is not 2 spacesIndent each nested block by exactly 2 spaces.
E003Indentation does not line up with an outer blockLine up the line with an outer block.
E004Unterminated textClose the text with ". Use triple quotes for multiple lines.
E005Unexpected characterRemove the character. Text uses double quotes.
E006Symbol operator used where Cluub uses a wordUse is, is not, and, or, not.
E010Unexpected token / syntax errorRead the message: it says what was expected and what was found.
E011Unknown top-level declarationA file contains declarations: model, store, client, service, api, page, component, layout, test, app.
E012Unknown member inside a declarationEach declaration kind allows specific members; the hint lists them.
E013Unknown view elementUse a known element, or a Capitalized component name.
E101Duplicate declarationRename one of the declarations.
E102Declaration name must be PascalCaseRename to PascalCase.
E103Field, action, state or parameter name must be camelCaseRename to camelCase.
E104Unknown dependency in usesFix the spelling, or declare the dependency.
E105Unknown nameFix the spelling, or create the value with let.
E106Dependency used without usesAdd uses X to the declaration.
E107Unknown action, route or store methodUse an existing action/route/method; the hint lists them.
E108Wrong arguments in a callMatch the parameter names and count.
E109Unknown model fieldUse a field that exists on the model.
E110Assignment to a name that was never createdCreate it first with let (or state on a page).
E111Name created twice in the same blockUse name = value to change an existing value.
E112input/checkbox must be bound to stateDeclare page state and bind the input to it.
E113Event handler must be an action callEvents call actions: on click save or on click remove(item.id).
E114Wrong component propertiesPass the properties the component takes.
E115Duplicate route or action nameRename the duplicate.
E116Unknown layoutDeclare the layout or fix its name.
E117Api or action called while a view is drawnViews only show data. Load it into state in when loaded or an action, then show the state.
E120Test-only statement used outside a testMove the statement into a test.
E201Layer rule violatedFollow page → api → service → store/client.
E202Circular dependency between servicesMove shared logic into a third service.
E203Components and layouts cannot use dependenciesPass data to components with takes.
E204AI called from the UI layerCall AI from a service and expose it through an api.
E205Environment secret read from the UI layerRead env in a service; send only what the page needs.
E301Declaration is in the wrong folderMove the file to the folder for its kind.
E401Hard-coded secret detectedMove the secret to .env and read env.NAME.
W101Unused dependencyRemove the unused dependency.
W102Action is too long (Single Responsibility)Split the action into smaller ones.
W103Service has too many actions (Single Responsibility / Interface Segregation)Split the service by responsibility.
W104Missing about descriptionAdd an about line.
W105State is never usedRemove the unused state or show it.
W106Page has no viewAdd a view block.
W107Layout without exactly one slotPut one slot where the page should appear. With none the page is hidden; with two it appears twice.
W108Unknown app settingUse one of about, port, ai, aiModel; other settings are ignored.

Codes starting with E are errors (the build stops). W codes are warnings. Suggestions use W104.
